## Findings

1. **[P2] Bound JPEG dimensions before decoding and displaying them.** `desktop/src/documents/images.mjs` accepts JPEG using SOI/EOI alone, whereas it parses PNG dimensions and enforces 16 megapixels. `desktop/src/ui/docs/reader.js` and `desktop/src/ui/docs/images.js` immediately assign every admitted saved URI to an image. New imports also call `createImageBitmap` before inspecting decoded dimensions, so their check happens after the decoder has already accepted allocation work. My independent header-admission reproduction advertises JPEG SOF0 dimensions 65,535 × 65,535 and is admitted as `{ok:true,mime:'image/jpeg',bytes:23}`. This synthetic header does **not** demonstrate successful native decoding or memory exhaustion; it demonstrates that the claimed pre-decode dimensional bound is absent. A sufficiently compressed, valid JPEG above the intended pixel limit can follow these same unguarded paths. Parse bounded JPEG segments/SOF dimensions before either bitmap decoding or image assignment, fail closed for unsupported/malformed headers, and add oversized/invalid/ordinary JPEG fixtures. Apply the same parser on existing reads and new import.

2. **[P2] Preserve unsupported reveal state through the table public projection.** `desktop/src/windows/presentation-deck.mjs` returns the table public card before copying `reveal:true`. The new table canvas renderer explicitly refuses a reveal table, but it never receives this flag for actual saved decks. My independent reproduction saves a genuine ProjectStore table with `reveal:true`, reads it through an actual authorized `NativePresentationDecks` grant and confirms that public cells are present while `reveal` is absent. Thus imported reveal tables now show their entire content instead of retaining the existing explicit unsupported-reveal refusal used for text/title cards. Preserve the flag so the renderer refuses, or reject unsupported reveal tables before exposing their cells; add a regression through the actual projection boundary, not only a direct renderer call.
