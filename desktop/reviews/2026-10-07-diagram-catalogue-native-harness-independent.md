## Demonstrated harness defects

**H1 — `--package` is silently ignored in this original harness.** There is no argv parsing, package identity read/copy or packaged launch option. Line 30 always calls `launchDesktop({extraArgs:[test-root,test-project]})`; `drive.mjs` defaults to workspace `node_modules/electron/dist/electron.exe` with the current root. I evaluated that exact retained launch line in an isolated VM supplied `process.argv=['node',...,'--package','C:/ignored-copy']` and a recording stub launch. It still passed only development test-root/project arguments, with no executable/packaged fields. This does not execute Electron. A COMPLETE from the original harness with that flag would therefore provide no copied-package evidence. Root had already identified this limitation and is correcting it separately; originals remain unchanged.

Exact correction: parse/reject CLI arguments explicitly; reject missing `--package` value/unknown flags; load the chosen BUILD-IDENTITY, preserve a fresh copy and verify its source/ASAR/runtime/helper identities; use its actual `appRelativePath` with `packaged:true`; put owned test data/session selection into that copy's Data directory; capture mode and the exact executed identity in the receipt; verify executable/archive/helper hashes after execution. Retain the current developer mode as an explicit separate branch. `tests/native/diagram-pan-release.mjs:11-26` is the existing copied-launch pattern, but extend it with required argument validation and full identity verification rather than silently accepting absent values. No package correction was made by this reviewer.

**H2 — Style case description exceeds/contradicts its assertions (`diagram-catalogue.mjs:42-43`).** It claims Style caret preservation without recording/comparing `selectionStart`/`selectionEnd`/direction. It says Save succeeds at version1 while the actual wait asserts version2. This is a demonstrated evidence-label defect, not a demonstrated product defect. Either qualify the description to “value and focus; Save advances origin from version1 to version2”, or add the missing selection observation/assertion and still correct the version wording. Do not rewrite the retained original receipt.
