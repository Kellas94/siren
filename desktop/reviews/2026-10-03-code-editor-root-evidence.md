# Source-backed Code editor implementation

Author: /root. Scope: isolated state/persistence adapter, actual EditorView module and local build seam. Production main/preload/package integration and all-window save/Lock barriers remain open; no editable satellite is enabled by this batch.

`editor-adapter.js` keeps actual immutable CodeMirror state with explicit LF handling, preserving BOM, literal CR and UTF-16 source offsets. Each admitted change persists through the real sourceClient and native draft receipt in order; unequal-length multi-range edits shift later offsets correctly. The complete transaction is checked for Unicode, insertion/queue/whole-source and intermediate native-version budgets before any prefix is sent. Undo/Redo use the same durable edit path. A partial native refusal retains every local edit, accurately retains the accepted native prefix and fences later changes.

`flush()` synchronously blocks new edits, coalesces callers, waits for accepted edits and returns the exact native source commit receipt. It does not acknowledge a Docs row or selected workspace manifest. `recovery-degraded` remains visible. Completion observers cannot revoke source ownership or dispose the editor and still receive an obsolete successful open/save; later observers stop when the client's identity or disposed/fenced state changes.

`editor.js` implements a real virtualized EditorView with patched Python language/highlight, keyboard Undo/Redo/Find/Save, Tab indent, full-model search, wrap toggle and light/dark colors. Its restrained toolbar and status distinguish opening, pending draft, saved source and retained local failure. The search input adapter updates the stock search state for a pasted query immediately followed by Enter. `build/code-editor.mjs` emits a local deterministic bundle using the pinned runtime closure, exact frozen Python extraction and all retained MIT notices; no source map is generated. It is not mounted in the production renderer yet.
