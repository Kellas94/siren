## Implemented scope

The pinned main BrowserWindow acquires a registry grant only through trusted native activation after PIN unlock. Code/Docs shells use separate sandboxed, isolated preloads, exact role/UUID URLs, hashed inline CSP and a positive package/resource allowlist. Hidden factories are registered and revalidated before ready/show. Only the workspace may open eligible Code/Docs entities; a satellite may focus/close itself, and cannot request all windows, the full legacy bootstrap, arbitrary files or a renderer-selected project/role/epoch. Native-owned active Docs and schema-2 source reference IDs form the roster; cached/release/provenance-only IDs never grant access. Presentation admission is deferred to its coordinated transport.

Selection, PIN Lock, account transition and quit retire registered and hidden pending shells. Failed native destruction is retained and fences future admission; Lock returns failure rather than claiming protection. Aborted selection/access/quit can explicitly reactivate only the pinned owner under current policy. These shells contain no editor state, source bytes or independent autosave bags. Dirty-view flush coordination and editor detach/attach are later tasks; this foundation is not advertised as those features.

Geometry restores normal bounds in current DIP workAreas, including negative coordinates/missing displays; it never copies content or rescales by DPI. Native factories consume current screen workAreas. Persistent layout, monitor commands and physical multi-monitor qualification remain pending.

The native legacy save owner now recognizes identical selected JSON only after live permission, owned writer, schema and exact CAS checks. Such a verified save keeps the original revision/pointer bytes. Private recovery is not a workspace selection and cannot suppress a real commit. Native readback still verifies exact requested JSON/hash/receipt; recovery checkpoint refusal remains RECOVERY_DEGRADED/ok:false, including unchanged receipts. The unprivileged adapter retains typed unchanged metadata and independently hashes any degraded workspace receipt. No stale CAS or checkpoint error was converted to success.

The documented `npm run build:renderer` previously omitted required baseline/output arguments and failed Usage validation. Its script now supplies the existing frozen baseline and generated directory; actual command completed. No baseline change or dependency addition occurred.
