## Contracts and bounds

Pure self-contained createDocumentActivityContract() exports frozen limits, page(document,options), compare(beforeBlocks,afterBlocks), locate(blocks,id). Browser window.SirenDocumentActivity is injected by build helper using the identical function. No native runtime import is needed.

page options: section comments/revisions/review, filter all/open/resolved, cursor original source position (nonnegative integer), limit1..20. Result {ok,rows,nextCursor,total,scanned,limited,code?}. Records retain original position, never merge duplicate IDs. Each row {position,kind,title,fields:[{key,text,truncated}],blockId?,state?,canCompare?,blockCount?}. Inert scalar excerpts at most4096chars, per-row16384chars, per-page131072chars; at most256source positions scanned per page. Unsupported/malformed rows are shown explicitly; resolved only actual boolean, unsupported states never counted open/resolved. Review combines one recorded document/review summary then trail positions then releases; all statuses/hashes/approvals are recorded claims, signoffFromFile displayed, never inferred verified identity/signature/test. Unknown fields remain in Preserved fields/exact export.

compare: complete block values canonicalized, not visible text. At most256blocks per side, aggregate1MiB UTF8 JSON,32768nodes,depth32. Require unique wellformed nonempty string IDs <=200UTF16units. Return {ok:true,identical,rows:[{id,change:added/removed/changed/unchanged,reordered,beforeIndex,afterIndex}],counts} or explicit {ok:false,code} for invalid/ambiguous/budget/unsupported input; never partial identical. Include complete unknown/sourceRef/image/formatting values; pointer equality is not source-byte/test equivalence. Plain JSON only, reject getters/symbols/functions/prototype/container anomalies without invoking imported code. Input objects stay byte-exact.

locate: exact ID lookup with unique-ID proof, maximum4096blocks scanned, same valid-ID rules, returns {ok:true,index} or BLOCK_MISSING/BLOCK_AMBIGUOUS/BLOCK_ID_INVALID/BLOCK_LOOKUP_LIMIT. Never CSS interpolate IDs.

Controller interface: SirenNativeDocsActivity.create({host,button,enabled,onJump,onCompare,onStatus}) returns setContext({document,version,sha256,dirty,readonly}), updateState({dirty}), invalidate(), pause(), resume(), dispose(). setContext receives retained saved document once per admission/save; avoid draft/document clones on every keystroke. onCompare({position,against:'saved'|'working'}) callback returns model.compare for chosen archived.blocks vs explicit current target. Controller has comments All/Open/Resolved, original-position pagination, Changes compare with explicit saved/working context, recorded Review & releases copy. No applyDocument/setContent/save/export callbacks or mutation bridges. Late callbacks/stale tokens/pause/dispose cannot repopulate private DOM. Opening Activity preserves focus/selection/pending rich/context/image state; explicit Jump alone may move focus. Model never stamps provenance or normalizes saved data.
