# SIREN SVG Pack

This pack contains implementation-ready SVG assets for the selected SIREN identity direction based on the approved concept board.

## Brand architecture
- Corporate: **T-INDUSTRIES**
- Product: **SIREN** (stylized visually as **SIR≡N**)
- Primary lockup: **SIR≡N** + **BY T-INDUSTRIES**
- Enterprise/documentation lockup: **T-INDUSTRIES | SIREN** + descriptor

## Notes
- The custom **E** is represented as a three-line diagram-syntax motif with three distinct terminal forms: square, circle, diamond.
- Colors are optimized for a neutral enterprise UI and can be adapted in CSS by swapping the variables in `design_tokens.json`.
- These SVGs are implementation-friendly and can be used directly in web apps, docs, and exported assets.

## Trademark caution
This package is a design pack only, not legal clearance. The name **SIREN** should still be checked by trademark counsel before commercial release.
